# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-17

### Added

#### CI/CD Skills
- `github-actions-advanced.md` — Advanced GitHub Actions workflows, matrix builds, caching, OIDC
- `gitlab-cicd.md` — GitLab CI/CD pipelines, runners, DAG, environments
- `deployment-strategies.md` — Blue-green, canary, rolling deployment patterns

#### 容器化 (Containerization) Skills
- `docker-production.md` — Multi-stage builds, security hardening, image optimization
- `kubernetes-essentials.md` — K8s core resources, RBAC, networking, troubleshooting
- `helm-charts.md` — Helm chart development, templating, repository management

#### 云服务 (Cloud) Skills
- `aws-essentials.md` — Core AWS services, IAM, VPC, proven patterns
- `terraform-iac.md` — Terraform modules, state management, workspaces
- `serverless-patterns.md` — Lambda, API Gateway, event-driven architectures

#### 监控告警 (Monitoring) Skills
- `prometheus-grafana.md` — Prometheus exporters, PromQL, Grafana dashboards
- `logging-stack.md` — ELK and Loki logging pipelines, log aggregation
- `incident-response.md` — On-call workflows, runbooks, post-mortem templates

#### Community Files
- README.md with bilingual (EN/CN) documentation
- MIT License, Contributing Guide, Code of Conduct, Security Policy
- GitHub Actions CI workflow
- Issue templates (bug report, feature request)
- Pull request template
